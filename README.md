# SpringBoot_JobPortal
A production-focused backend application built with Java and Spring Boot. The project demonstrates REST API development, database persistence, authentication and authorization, containerization, and integration with a React frontend. 

# Project Attribution
The frontend for this application was provided as part of the Spring Boot course and serves as the client interface for the application.
I developed the backend independently, including the Spring Boot application, REST APIs, business logic, database integration with JPA, and backend configuration. I also integrated the backend with the provided React frontend.
The project is based on the concepts and architecture taught throughout the course, with additional backend implementation and configuration completed as part of my own development work.

# Features
RESTful APIs using Spring Boot
Spring Data JPA for database persistence
Spring Security for authentication and authorization
Role-based access control
Input validation
Global exception handling
Database integration
Docker containerization
React frontend
API integration between React and Spring Boot
Environment-based configuration
Unit and integration testing
